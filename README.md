# Эхо Эйры

**Сайт-витрина вымышленного мира в жанре Dark Fantasy.**
Четыре империи, одна пустыня, одно небо. Война, которая никогда не заканчивается.

[🔗 Открыть живую версию сайта](https://falanger888.github.io/echo-aera/)

## О проекте
Статический сайт-витрина на чистом HTML, CSS и JavaScript (ES Modules). Без фреймворков, сборщиков и зависимостей. 

Реализованы: интерактивная SVG-карта, хронология с фильтрами, атлас городов, инструмент сравнения регионов, дипломатическая матрица, тест "Кем бы ты был в Эйре" и пролог.

## Технологии
- HTML5 (семантическая верстка)
- CSS3 (Grid, Flexbox, CSS Variables, анимации)
- Vanilla JavaScript (ES Modules, кастомный рендеринг компонентов, data-driven подход)
- GitHub Pages (хостинг)

## Структура
- `js/core/` — ядро (навигация, поиск, эффекты)
- `js/pages/` — логика страниц (регионы, персонажи, квиз)
- `js/data/` — данные мира (JSON-структуры)
- `js/components/` — шаблоны шапки и подвала
